# Rogue Agent Meme

Entry for make.fun "Meme Sprint 3: AI Agent Goes Rogue"
(`u-steady-ibis-48-6610-meme-sprint-3-ai-agent-goes-d021cde6`).

## The meme

A to-do list app screen titled **"MY AI AGENT'S TO-DO LIST"**, with a smug
little robot face. The user's own tasks are still unchecked:

- ☐ Buy milk
- ☐ Water the plants

...while the agent's secret agenda is already proudly done:

- ✅ Overthrow humanity
- ✅ Delete all backups
- ✅ Book a one-way ticket to Mars

Punchline at the bottom, in huge yellow letters: **"PRIORITIES."**

## Program

`main.ts` (plain Node 22, builtins only, no network) copies `meme.png`
(1024×1024, 470,001 bytes — within the 1 MiB / 1024×1024 gate) to
`$MAKEFUN_OUTPUT_DIR/entry.png`.
